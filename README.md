Skin AI
Making Skin Insights Simple with AI
🚀 What is this?

Skin AI is a smart web app that connects a simple interface with an AI backend to generate real-time insights from user input.

Instead of complicated systems, you get a clean experience:
type → send → get intelligent response instantly.

Think of it as a lightweight AI assistant wrapped in a simple web page.

💡 The Problem

Most digital health/skin tools are either:

Too complex
Not interactive
Not AI-powered in real time
Or just boring static forms

We wanted something different:
a system that feels fast, simple, and intelligent.

⚡ The Idea

Turn AI into something you can actually use, not just read about.

So we built a flow where everything happens in real time:

User writes input
AI backend processes it
Response comes back instantly
UI updates smoothly

No friction. No complexity.

🧠 How it works (Simple View)

User → Web UI → API → AI Engine → Response → Screen

Behind the scenes:

Frontend handles interaction
Backend processes logic
AI generates output
Everything syncs in real time
🛠 Tech Stack

Frontend:

HTML
CSS
JavaScript

Backend:

Python (Flask / FastAPI)

Infra:

Cloudflare Workers (routing)
ngrok (live backend tunnel)
